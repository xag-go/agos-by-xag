  lists) are the owner's machine-wide pages; only his web holds their internal token.

  journal, the error alert queue, the shared-MCP sync, the one-off moves at start. A stale entry fails the test.

## 3. API fuzzing (Schemathesis) and ZAP

- **Per operation** (`test_api_fuzz.py`: 407 of the 414 operations of `openapi.json`; the 7 that act on the machine
  itself are left out). The last run before the fixes had 125 operations answering a 500 (289 sub-tests passed).
  Root causes: F3 (OverflowError, ~100 operations), F5 (6 routes), and rig gaps (no Hermes Python →
  `FileNotFoundError`, `hermes --version` empty) which the rig now answers like a down Hermes (503, not a finding) —
  `fuzz_rig.py`. After the fixes (`AGOS_FUZZ_EXAMPLES=3`, 2026-11-03 21:1x): 410 sub-tests pass, 4 operations still
  answer a 500 — all F5 (Hermes started on the event loop, `api/models.py` login routes, m2) — plus the suite's
  strict loop-guard error for the same 6 routes. The nightly runs 25 examples per operation.
- **Chained through real rows (not Schemathesis's stateful phase).** Before the operation cases, every create (a
  POST on a collection; 58 are tried) is called with generated valid input until one answers an
  id; the operations under it then get that real id in most cases (create → read → update → delete and its
  sub-resources). On the rig 10 creates answer an id (automations, board views, chats, kanban, labels, list folders,
  worker DMs/groups, brain, owner rules): **64 of the 414 operations** run on a real row. A test fails when fewer
  than 8 creates work, so the chaining can't silently go away.
- **Schemathesis's own stateful phase does not run on this API yet**: its CLI infers 10,633 links but ran 0–1
  scenarios and covered 0 links (its root-transition scheduler disables every rule; also with the fuzzing phase
  first). It was taken out of the nightly rather than reported as coverage; declaring OpenAPI `links` for the 10
  working creates is the next step (it changes `openapi.json`, so it goes with the owner of the API contract).
- **ZAP baseline** (`zap_baseline.py`: spider + passive rules on the web build in front of the browser tests' light
  core; ZAP 2.17.0 and Temurin JRE 21 pinned by SHA-256, no Docker needed) runs in the nightly job `security-scans`
  (`.github/workflows/nightly-hermes.yml`, self-hosted runner, after the real-Hermes job). **Not run on the runner machine this
  round** (RAM alert: the ops VM has priority); its first result is the first nightly's artifact.
- **SBOM**: job `sbom` in `.github/workflows/security.yml` — CycloneDX 1.5 for Python (`uv export --format
cyclonedx1.5` from `uv.lock`) and for Node (`@cyclonedx/cdxgen@12.9.0 -t pnpm`, lockfile only), uploaded as the
  `sbom-cyclonedx` artifact (90 days).
