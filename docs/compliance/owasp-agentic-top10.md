# OWASP Top 10 for LLM Applications (2025) + Agentic AI threats: AGOS assessment

Assessed commit `33e135a1` (2026-11-02). Agentic threat IDs follow the OWASP Agentic Security Initiative Top 10
(ASI01 goal hijack, ASI02 tool misuse, ASI03 identity/privilege abuse, ASI04 agentic supply chain, ASI05 unexpected
code execution, ASI06 memory/context poisoning, ASI07 insecure inter-agent communication, ASI08 cascading failures,
ASI09 human-agent trust exploitation, ASI10 rogue agents). `core/` = `services/core/src/agos_core/`; "sec §n" =
the maintainers' internal security audit (not in the repository). Legend and lane codes: [README.md](README.md).

## The core risk in one line

The Co-Founder can read untrusted content (web search/extract on by default), holds private data, has open internet
egress, **and** can run persistent, owner-level actions in the same turn without asking. That is the full "lethal
trifecta" plus persistence. Rows 1, 6 and 7 below are the three parts of one fix.
