# OWASP ASVS 5.0, Level 2: AGOS assessment

- Assessed commit: `33e135a1` (`main` = `eng/foundation`), 2026-11-02. Status is for that commit; fixes already
  committed on a lane branch are shown as "in flight" with their SHA and do not change the status until merged.
- Architecture assumed (ARCHITECTURE.md §10-12): one owner, no login; web `:3000` and core `:8766` bind 127.0.0.1;
  remote use only through `tailscale serve`; per-workspace Hermes gateways (Landlock wall) and Docker sandboxes;
  SQLite. Requirements are checked at ASVS 5.0 section level; legend and lane codes are in [README.md](README.md).
- Evidence sources: code at the commit (paths below are relative to the repo; `core/` = `services/core/src/agos_core/`),
  the maintainers' internal security audit of the same commit (not in the repository; cited as "sec §n"), and commands run for this review.
