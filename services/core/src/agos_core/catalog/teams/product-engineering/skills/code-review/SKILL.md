# Code review

1. Does it do what the card asked, and nothing else?
2. Are there tests for the new behaviour and the edge cases?
3. Names say what things are; no dead code is left.
4. Name the risk (data, security, speed) and how it was checked.
   Answer approve, or changes with a numbered list.
