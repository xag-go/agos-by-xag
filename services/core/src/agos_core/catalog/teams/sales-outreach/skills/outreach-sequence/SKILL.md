# Outreach sequence

1. Day 0 — first message: why them, why now, one question.
2. Day 3 — follow-up: one new useful thing (a link, an idea), same question.
3. Day 8 — last note: close the loop politely; leave the door open.
   Never send more than three messages to one person.
